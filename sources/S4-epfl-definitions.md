# S4｜EPFL CMi〈Etch definitions〉

- 網址：https://www.epfl.ch/research/facilities/cmi/process/etching/etch-definitions
- 讀取日期：2026-11-21
- 類型：瑞士洛桑聯邦理工學院（EPFL）微奈米技術中心無塵室官方頁

## 重點筆記（中文轉述）

1. 蝕刻是移除一層或多層材料；用圖案當遮罩，只蝕刻晶圓上指定的區域。分為濕式和乾式。
2. 濕式蝕刻：用液體蝕刻劑，樣品通常整個泡在槽裡。選擇比高，通常只有一層會和液體反應。大多是等向性。
3. 等向性：各方向蝕刻速率相同，會造成遮罩下方側向被吃掉，叫做底切（under-etch／undercut）。
4. 乾式蝕刻用離子、氣體或電漿，分三類：
   - 離子束蝕刻（濺擊）：離子加速撞擊，物理性移除；任何材料都能非等向蝕刻，但材料間選擇比有限。
   - 氣體蝕刻：反應性氣體和材料化學反應；選擇比高、等向性；常用來清掉整個表面，或移除犧牲層做出懸空結構。
   - 電漿蝕刻（RIE）：化學＋物理反應同時發生；選擇比好控制，可精準做非等向的圖案轉移。深矽蝕刻是可做高深寬比結構的成熟例子。
5. 名詞定義：
   - 選擇比（selectivity）：目標材料蝕刻速率 ÷ 遮罩或底層材料蝕刻速率。
   - 非等向性（anisotropic）：不同方向蝕刻速率不同。
   - 深寬比（aspect ratio）：結構的高度和寬度的比。
   - 均勻度（uniformity）：整個暴露區域蝕刻速率的一致程度。
   - 終點（end-point）：一層剛好蝕刻完的時間點；終點偵測（EPD）是即時感測這個時間點的系統。
   - 過蝕刻（over-etch）：到終點後再多蝕刻一點，補償不均勻和微負載效應。
   - 停止層（stop-layer）：目標層下方不會被蝕刻的層。
   - 鈍化（passivation）：保護表面（通常是側壁）不被蝕刻，讓蝕刻有方向性。
   - 離子（ions）：帶電的原子或分子。
   - 自我偏壓（DC-bias）：電漿蝕刻時，下電極加 RF 功率後會累積負的直流電位，把離子加速打向樣品。
   - 副產物（by-products）：化學反應產生的物質。
   - 自由基（radicals）：電漿中產生、帶未成對電子、反應性很高的中性粒子。
   - 微負載效應（micro-loading）：局部蝕刻速率會受圖案密度和尺寸影響。
   - 光學放射光譜（OES）：分析反應時發出的光來判斷終點的方法。
